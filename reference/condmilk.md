# Condensed milk

Manufacturers' stocks of evaporated and sweetened condensed milk: Jan
1971 – Dec 1980.

## Usage

``` r
condmilk
```

## Format

Time series data

## Source

Makridakis, Wheelwright and Hyndman (1998) *Forecasting: methods and
applications*, John Wiley & Sons: New York. Exercise 7.5.

## Examples

``` r
plot(condmilk)

seasonplot(condmilk)

tsdisplay(condmilk)

```
