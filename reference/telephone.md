# Telephone cost

Cost of a telephone call between San Francisco and New York: 1915–1996.

## Usage

``` r
telephone
```

## Format

Time series data

## Source

Makridakis, Wheelwright and Hyndman (1998) *Forecasting: methods and
applications*, John Wiley & Sons: New York. Chapter 9.

## Examples

``` r
plot(telephone)

```
