# Shipments

Shipments over 15 periods, showing a cubic trend pattern mixed with some
randomness.

## Usage

``` r
shipex
```

## Format

Time series data

## Source

Makridakis, Wheelwright and Hyndman (1998) *Forecasting: methods and
applications*, John Wiley & Sons: New York. Exercise 3.1.

## Examples

``` r
plot(shipex)

```
